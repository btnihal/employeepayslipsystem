# Employee Payslip Generation System

A Django-based Employee Payslip Generation System developed as a machine task.

## Features

### Employee Management
- Add employees
- View employee details
- Edit employee details
- Delete employees

### Payslip Management
- Select employee
- Select salary month
- Enter leave count
- Automatically calculate salary
- Calculate HRA, DA and other allowances
- Calculate PF and ESI deductions
- Generate payslip
- Print payslip
- Prevent duplicate payslips for the same employee and month

### Dashboard
- Total employee count
- Total payslip count
- Recent employees
- Recent payslips

### Payslip History
- View all generated payslips
- View individual payslip details

## Technology Stack

- Python
- Django
- SQLite
- HTML
- CSS
- Django Templates
